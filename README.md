# Répartition km — Hilario Déménagement

Calculateur de répartition du tarif kilométrique pour les livraisons de meubles.

## Utilisation

Ouvre simplement `index.html` dans un navigateur — aucune installation requise.

## Fonctionnalités

- Saisie des kilomètres directement sur l'écran principal
- Répartition visuelle : donut, barres, barre empilée
- Manutention absorbée par le surplus
- Statut rentabilité en temps réel
- Panel paramètres (bouton ⚙) pour personnaliser tous les coûts

## Paramètres disponibles

| Catégorie       | Paramètres |
|----------------|------------|
| Équipe          | Nombre de déménageurs, coût horaire, vitesse moyenne, tarif/km |
| Carburant       | Consommation (L/100km), prix du carburant |
| Véhicule        | Valeur d'achat, durée amortissement, km annuels, assurance, vignette, entretien, location |
| Frais fixes     | RC professionnelle, téléphone |

## Déploiement
